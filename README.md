# Conversor de Fusos UTM

Ferramenta desenvolvida para converter coordenadas entre diferentes fusos do sistema **UTM (Universal Transverse Mercator)**, oferecendo suporte tanto para coordenadas individuais quanto para arquivos geoespaciais.

## Funcionalidades

* Conversão de coordenadas UTM entre diferentes fusos.
* Conversão de coordenadas individuais.
* Extração e conversão de coordenadas contidas em arquivos **.KML** e **.KMZ**.
* Processamento rápido e simplificado para grandes quantidades de pontos.

## Objetivo

Facilitar a migração e a padronização de coordenadas UTM, reduzindo o trabalho manual e minimizando erros durante a conversão de dados geográficos.
